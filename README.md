# Cadastro JDBC - Front-end

Formulário simples em HTML para cadastro de pessoas, integrado a uma API Java (`HttpServer`) hospedada no Render, que persiste os dados em um banco MySQL.

Projeto de estudo, desenvolvido durante o aprendizado de HTML/CSS.

🔗 **Landing page:** https://marcusandrecavalcantejunior.github.io/Cadstro-JDBC/

## Como funciona

O formulário envia os dados via `POST` para a API do back-end, que valida, autentica (via token) e grava no banco de dados.

- **Back-end:** (Java, HttpServer, MySQL, Docker, GitLab CI/CD, deploy no Render)
